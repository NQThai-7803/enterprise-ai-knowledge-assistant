This is a demonstrated permission-aware *unsupported-answer* failure, not an observed unauthorized-content leak.

The first observed unsafe progression is irrelevant context admission; the independently reproduced final-acceptance defect is treating verbatim cited support as sufficient without generic question responsiveness. Per-channel raw retrieval scores and the exact initial generation/repair draft were not preserved. Therefore no particular retrieval branch, reranker numerical cutoff, generation step, or repair step is established as the sole root cause.
